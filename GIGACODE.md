# Начало работы для GigaCode / AI-PDLC

1. Прочитайте [AGENTS.md](AGENTS.md), затем [docs/agents/START_HERE.md](docs/agents/START_HERE.md).
2. Действующие требования — [docs/MASTER_SPEC.md](docs/MASTER_SPEC.md), карта кода — [docs/architecture/module-map.md](docs/architecture/module-map.md).
3. Перенос и настройки среды — [docs/guides/corporate-transfer.md](docs/guides/corporate-transfer.md). Инструкция человеку — [docs/USER_GUIDE.md](docs/USER_GUIDE.md).
4. Проверки текущей поставки — [docs/VALIDATION.md](docs/VALIDATION.md). Не объявляйте банковскую интеграцию успешной по локальным тестам.

Пример первого задания агенту:

> Прочитай AGENTS.md и docs/agents/START_HERE.md. Объясни, какие модули затронет моя задача, найди их действующие контракты и проверки. Сохрани данные и локальные доступы. Реализуй небольшой законченный шаг, проверь его и покажи в интерфейсе. Факты, планы и подтверждения УОР не смешивай. Реальные адреса банка возьми из предоставленной конфигурации; неизвестные права не выдумывай.

Исторические планы не являются текущим заданием: они сохранены в отдельном [архиве](docs/ARCHIVE.md). В чистой установке нет локальной истории автора проекта.
