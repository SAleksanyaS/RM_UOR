# Рабочее место УОР ДИТ Operations

УОР — управление обеспечения развития.

Локальное веб-приложение для директора ДИТ, ИТ-лидеров кластеров и кураторов УОР. Каждый компьютер получает общие определения и намеренно опубликованные данные из Git, а источники запрашивает с собственными правами.

Версия 0.3.0 · 25.10.2026. Реализованы самостоятельная настройка цели, загрузка фактов, исполнение, подтверждение, отчётность и управляемая публикация. Добавлены полный профиль презентации модели зрелости, перенос рабочей базы с файлами, управляемое хранение и восстановление после неудачного обновления программы. Компактное меню раскрывается в подписи; обзор показывает общий результат и полноту данных. Реальные HTTP, Confluence, Qlik Engine и браузерный сбор заменили прежние заглушки. Корпоративные адреса, права, сертификаты и поддержка конкретного Сбербраузера проверяются при настройке в банке; локальные стенды не подтверждают доступ в корпоративную сеть.

## Запуск

Нужны Node.js 22.20+ ветки22.x либо24+, npm, Git и браузер. Python не требуется. Выполните из разрешённой папки:

```text
npm ci
npm run dev
```

Для рабочей установки сначала задайте разрешённые корни и адрес Git по [инструкции](docs/guides/setup-and-run.md). Запуск открывает браузер; иконка приложения и отдельный установщик не требуются. Локальная служба слушает только127.0.0.1. Режим куратора настраивается локально; пароль или код в репозиторий не попадают.

**Роли:** обычный пользователь видит результаты, планы и отчёты; куратор — настройку целей/источников, импорт, проверку и публикацию. Вход по имени и паролю. [Роли и локальные аккаунты](docs/guides/roles-and-accounts.md) · [что можно доделать здесь и что требует банка](docs/remaining-by-environment.md).

## Что доступно

- Обзор всех целей ДИТ, статус и остаток, персональные результаты ИТ-лидеров, направления и матрица. Показатели разных целей не усредняются. Большая матрица разбита на страницы, выбор столбцов и фильтры сохраняются для личного профиля.
- Мастер создания и изменения цели: полный русский паспорт, показатели, шесть методик, официальные/внутренние пороги, участники, команды, владелец, источник и пробный расчёт. [Самостоятельная настройка](docs/guides/self-service-goal.md).
- Excel модели зрелости и настраиваемые XLSX/UTF-8 CSV/вставка таблицы для других целей: сопоставление, предпросмотр, явное принятие, сохранённый профиль, история и проверка сопоставимости периодов.
- Получение по HTTP/Confluence, Qlik Engine и воспроизведение записанных действий Chromium-браузера. Личные профили доступа настраиваются формой и остаются на компьютере. Есть ручной вход, запись сценария, ограниченные повторы, отмена, расписание при работающем приложении, отдельные ошибки прав/сети/сертификата/формата. [Корпоративный runbook](docs/BANK_CONNECTORS_RUNBOOK.md).
- Планы по цели и ИТ-лидеру, пакеты работ, вехи с владельцами и сроками, зависимости без циклов, базовый план и диаграмма сгорания. Численный прогноз строится только по нескольким сопоставимым фактам. Проверки удержания и очередь куратора. [Гайд](docs/guides/execution-and-retention.md).
- Положительный расчёт ждёт отдельного подтверждения УОР. Комментарий или доказательство обязательны. Изменение фактов/правил и ухудшение автоматически лишают старое подтверждение силы. Библиотека файлов проверяет целостность и происхождение.
- Отчётный снимок, недельное сравнение, выбранные цели/лидеры/период, HTML/печать и PPTX. Пользователь загружает шаблон, связывает текстовые блоки и таблицы с полями отчёта, задаёт повторы слайдов. Новые снимки сохраняют историческую методику и организационные имена; недостающая история явно неизвестна.
- База знаний, продукты, ИТ-услуги, лидеры продуктов, статьи, назначения, архив и проверка связанных объектов. Повестка директора и решения с владельцем/сроком.
- Публикация выбранных черновиков, проверенных снимков, подтверждений, доказательств и шаблонов. Независимые правки объединяются; конфликтующие значения выбираются по полям с проверкой актуальности предпросмотра.
- Обслуживание: диагностика среды, согласованные копии SQLite, проверяемое восстановление с откатом, политика хранения, совместимость общего выпуска и миграции локальной схемы. [Обновление программы](docs/guides/code-update.md) из UI использует проверенный переход вперёд, установку зависимостей и перезапуск.

## Общая информация и личные данные

Общие изменения попадают в `release/current`. Руководитель УОР выпускает их слиянием в `main` через Git UI. Пользователь выбирает «Обновить данные»: сначала общие определения, затем нужные источники и расчёт. Программа отдельно обновляется в разделе обслуживания.

Личная база, исходные файлы, браузерный профиль, сертификатные пути, диагностика, резервные копии и секреты находятся в исключённой из Git `.runtime`. Только выбранные проверенные данные публикуются намеренно. В публичном RM_UOR используется `demo-only`: код и синтетические примеры; импортированная рабочая карта не отправляется.
