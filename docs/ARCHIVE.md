# Где хранится прежняя история

`main` и `release/current` начинаются чистой исходной версией0.4.0. Новая установка не получает журналы локальной разработки. Её собственные события появляются после действий пользователей.

Полная прежняя Git-история, в том числе ранние планы, старые инструкции и акты проверок, сохранена отдельно в ветке `archive/pre-corporate-0.4.0-20261025` исходногоRM_UOR. Дополнительный проверяемый Git bundle подготовлен локально в `.runtime/exports/`; точное имя указано в акте передачи владельцу. В архивную ветку не направляются новые обычные изменения.

Для работы в банке используйте чистую кодовую поставку и новый внутренний репозиторий. Архивная ветка, bundle и личная `.runtime` не требуются для запуска. Если нужна историческая причина решения — ищите её в архиве, а действующий контракт проверяйте по текущим коду, мастерспеке и тестам.

После переписывания исходной истории старым локальным клонам нужен новый чистый клон/пакет. Не объединяйте несвязанные истории и не применяйте сброс к чужим локальным изменениям. Этот однократный переход прямо запрошен владельцем; обычный обмен данными продолжает использовать проверку версий и штатное слияние.
