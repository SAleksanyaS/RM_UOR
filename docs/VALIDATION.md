# Проверка целевой поставки0.4.0

Среда здесь: Windows x64, Node24.19.0, локальная разрешённая папка, временные синтетическиеGit/SQLite/HTTP-стенды. Банковские источники/ССО/сертификаты,СберОС/macOS иPowerPoint этой проверкой не считаются принятыми.

## Новые законченные сценарии

- Недельная сводка: собственный текст/неделя, роли/CSRF, owner isolation, CAS, частичный in-flight draft, читатель без утечки неопубликованного, ограничения ввода, реальныеGit release/current→main иUI.11 целевых тестов.
- Чистая установка: empty/demo, отказ перезаписывать существующую базу/настройки, отсутствие старых фактов, защита приватной папки.4 целевых теста.
- Кодовая поставка: чистый сохранённыйGit HEAD, фильтрация приватного/старой истории, SHA256manifest, безопасный пустойcatalog, пример аккаунтов, реальный export→setup, отдельныйPRIVATEархив, dirty tree/ссылки/WindowsADS/занятыйвыход.9 целевых тестов.
- УчётныйJSON: действующий вход по хешу, сохранениеID, placeholders, пустойпарольбезизменения, отказ на публичный путь/junction.4 целевых теста.
- Архивирование журнала: независимаяпровереннаяSQLite-копия+durablemanifest, точныеданные, retention, остановленныйlauncher/API-port, CLI иотказ на копии.10 целевых тестов. Это защита поддержанных способовзапуска, не формальная сертификация произвольного внешнего процесса или физического сбоя питания.

## Настоящее рабочее место

Выполнена history:archive при остановленном приложении. Перед очисткой создана и проверена отдельная полная копия в приватной .runtime/history-archive. Цели, факты, черновики, подтверждения, отчёты, шаблоны и хеш-реестр сохранены. В браузере0.4.0 проверены новая недельная страница / четыре поля / пустая общая сводка и нулевые счётчики операций/изменений. Примерный недельный текст не сохранялся как рабочий отчёт.

Старые планы, акты и конкретные рабочие цифры находятся в отдельном архиве; в чистую поставку они не включаются. Общий прогон объединённой версии: 97 файлов, 472 теста — все прошли. npm run build завершился успешно (TypeScript и production Vite). Одно-коммитная основа и финальный кодовый экспорт дополнительно проверяются по refs, manifest и пустой установке перед передачей. Приватные логи и снимки — .runtime/implementation/completion, не публичныйGit.
