# Уточнения заказчика и решения v0.2

24 октября 2026 года

| Тема | Актуальное решение | Что заменено/добавлено |
|---|---|---|
| Название | Рабочее место УОР ДИТ Operations | Уточнено название; УОР — управление обеспечения развития |
| Поставка | Подготовленная среда и npm run dev из разрешённой папки | Отменён текущий запрос на установщик/иконку/среды внутри пакета |
| Переносимость | Общая логика и платформенные адаптеры | Не обещаем, что любой сертификатный браузер работает одинаково на всех ОС |
| Первый этап | Данные уже в базе знаний, реальный сбор — заглушка | Фокус на расчётах, проверке, редакторе и визуализации |
| Обновление | Отдельно общие данные, все источники, выбранные, всё | Полный запуск сохраняет порядок Git → сбор |
| Старт приложения | Проверка новой версии с уведомлением | Не применять новый код скрытно во время работы |
| Статус действий | Этап, время этапа, общее время, итог | Распространяется и на сохранение/отправку |
| Редактирование | Самостоятельная настройка куратором через UI | Сохранение, журнал и отправка файлов выполняются приложением |
| Владельцы | Владелец цели отдельно от куратора и исполнителей | Добавлена отдельная ответственность за результат |
| Роль | Читатель либо индивидуальный кураторский код | Код проверяется локально, Git-права проверяются отдельно |
| Источник | Дашборд, страница/вложение, файл или ручной ввод УОР | Плашка способа, автора и даты |
| Доставка фактов | Личные и проверенные опубликованные снимки | Изменено прежнее правило «факты только локальны» |
| Подтверждение | Положительный результат ожидает УОР; нужен комментарий/артефакт | Добавлен финальный предметный контроль |
| Ухудшение | Автоматическое невыполнение без согласования | Подтверждение относится к старой оценке и остаётся в истории |
| Совместная работа | Независимые файлы и автоматическое объединение | Редкое совпадение одного поля не теряется молча |
| Выпуск | release/current → main через руководителя УОР | main читают пользователи; рабочую ветку видят кураторы |
| Изменения | Автоматические события и структурная разница версий | Понятные сообщения про веса, метрики, комментарии и данные |
| Директорский UI | Пофамильная картина ИТ-лидеров, иерархическая матрица | Обязательное измерение и несколько уровней детализации |
| Тестовый Git | Публичный репозиторий, документация/код/обезличенные примеры | Рабочие корпоративные данные импортируются локально |
| Перенос в банк | Отдельный AI-PDLC handoff | Конфигурация источников, Git, сред, прав, путей и данных |

Варианты улучшений не требуют нового цикла вопросов по каждому техническому решению. Для текущей проработки выбираются разумные настройки по мастерспеке; корректировки фиксируются по мере демонстраций. Первый этап приложения реализован; реальный корпоративный сбор остаётся отдельным этапом.

## Последующие уточнения текущего этапа

| Тема | Принятое решение |
|---|---|
| Главная | Компактная сводка, один график по ИТ-лидерам, три действия с раскрытием остальных |
| Детализация | Матрица и направления вынесены отдельно, длинные пояснения открываются по запросу |
| Направления | Архитектура; производственный процесс; управление технологическим долгом; данные; МЕТЛА; тарифные модели ИТ и SberInfra; состав и привязки редактирует куратор |
| Исходная категория | Сохраняется из карты и не подменяется направлением |
| Неоднозначные цели | Остаются без направления до решения куратора; рисковая цель не объявляется МЕТЛА по догадке |
| Итоги | Общее количество считает уникальные назначения; у цели одно направление либо отсутствующая привязка |
| Названия | Полные русские заголовки, код только дополнительный идентификатор |
| База знаний | Лидер продукта и явная связь с продуктом, отдельно от ИТ-лидера кластера |
| Знак | DO и подпись «РМ УОР»; файл `public/brand/rm-uor.png`; справа нет дополнительного «ДИТ» |
| Дизайн-система | Настоящие токены публичной SDDS Service Malachite; соответствие внутреннему стандарту проверяется при переносе |

Текущие действия и проверка — в плане `2026-10-24-overview-refinement.md`; статус реализации не выводится автоматически из этой таблицы решений.
