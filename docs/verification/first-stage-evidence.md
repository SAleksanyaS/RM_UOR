## Визуальная проверка текущего прохода

Не выполнена: инструмент CUA не смог запустить среду (`failed to write kernel assets`, Windows os error 3). Сброс среды не устранил проблему. Открытие локального адреса через приложение было поставлено в очередь; это не доказательство просмотра.

Не отмечаем проверенными размеры 1366×768, Full HD и узкий экран. Мобильное меню и доступность проверены чтением кода и компонентными тестами, но требуют фактического визуального осмотра. Предыдущие снимки до упрощения главной не выдаются за новые. Пользователь может открыть работающий интерфейс по локальному адресу.
