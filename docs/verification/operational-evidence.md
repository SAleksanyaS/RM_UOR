# Проверка операционного выпуска0.2.0

25.10.2026 · мастерспекаv0.7. Проверялся код в ветке implementation/operational-completion, исходная база54aab0a. Фактические проверки перечислены ниже; корпоративная приёмка отдельно в AI_PDLC_HANDOFF.md.

## Автоматические проверки

- Общий прогон:379 проверок,360 успешных и19 ошибок одного вида в завершении приложения (`waitBackground`). Во время интеграции служба получила новый lifecycle-контракт; после стабилизации повторены все10 затронутых файлов и интеграция публикации: **64/64 успешны**. Полный набор повторно не запускался.
- Адресные новые проверки:5 реальных Git-сценариев предпросмотра/конфликтов/состава; несовместимая комбинация методики и контура отклоняется до push, приватный чужой снимок не публикуется, устаревшая версия не проходит. Проверки UI выпуска и смены профиля также успешны.
- Исполнение:15 проверок DAG, базы, сгорания по событиям, сопоставимости прогноза, удержания, ресурсов, CAS, API и UI.
- Личные настройки/матрица:7 проверок профилей, повреждённых/недоступных настроек и ограниченной отрисовки1000 целей/40 лидеров. Матрица показывает максимум50 строк и16 лидеров за страницу; существующие8 лидеров видны вместе. Измерение модели1000 целей/назначений:668,45мс на локальном Node24; это не банковский нагрузочный SLA.
- Копии/восстановление/завершение фонового копирования:8 адресных проверок. Повреждённая структура/версия/хеш отклоняется; ошибка после установки возвращает все прежние пространства; прерванные операции и старые сессии не оживают; очистка считает только проверяемые копии.
- Сборщики: реальные локальные HTTP, WebSocket Qlik Engine и установленный Microsoft Edge; CSV/XLSX и профиль зрелости, запись/повтор, ручной вход, очередь, отмена, расписание, превышение размера/формат, изменение правил во время запроса и сохранение старых фактов. Дополнительно проверены запрещённый redirect/WebSocket/service worker, исключение входа/паролей из recorder и неверный Location. Банковские адреса не использовались.
- Обновление программы:6 адресных сценариев локального Git,2 UI. Точное соответствие origin/commit, запрет dirty/divergence/приватных отслеживаемых путей, CAS-заявка, порядок ff→зависимости→новый запуск. Читатель может обновить локальную программу; публикация остаётся кураторской. Не обновлялся реальный рабочий checkout из теста.
- Шаблоны/недельное сравнение/историческая основа/доказательства покрыты адресными проверками и общим прогоном. Сквозной тест публикует выбранные файлы/шаблон, сохраняет невыбранную правку локально, читает выпуск другим пользователем и новой offline-копией, отклоняет подмену байтов до изменения каталога.
- Финальная `npm run build` успешна: TypeScript и Vite. Начальный JS306,78КБ /94,89КБ gzip; отчёты, исполнение, источники, матрица и другие разделы отдельными ленивыми частями. Предупреждения Rollup относятся к аннотациям установленного zod, ошибок сборки нет.

## Локальный показ

Приложение запущено штатно `npm run dev`: UI127.0.0.1:5173, API4174, версия0.2.0, SQLite schema2. Рабочие импортированные данные остаются в приватной .runtime.

В in-app браузере фактически просмотрены обзор ДИТ, исполнение и удержание, получение данных с формой личного профиля и обслуживание. Создана согласованная копия текущего рабочего места через UI. Скриншоты находятся приватно в .runtime/implementation/completion и не публикуются с корпоративным набором. Проверка одного фактического размера окна не доказывает все размеры/macOS/СберОС.

Это проверка движка на исходнике, не полная привязка всех банковских полей и не визуальная приёмка в PowerPoint. Исходник и результат не входят в публичный Git.
