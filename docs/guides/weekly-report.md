# Еженедельный отчёт

Страница **«Еженедельный отчёт»** собирает текстовые сводки кураторов УОР за выбранную неделю. Неделя идёт с понедельника по воскресенье. Это объявленная информация о работе: сохранение текста не добавляет измеренные факты, не закрывает вехи и не подтверждает цели.

## Посмотреть опубликованное

1. Откройте **«Еженедельный отчёт»** в меню.
2. Выберите **«Отчётная неделя»**. Стрелки **«Предыдущая неделя»** и **«Следующая неделя»** позволяют перейти на неделю, которой ещё нет в списке.
3. Прочитайте карточки кураторов: **«Главная сводка»**, **«Главные выполненные задачи УОР»**, **«Требует внимания»**, **«Планы следующей недели»**. В карточке указаны автор и дата сохранения текста.

Обычный просмотр показывает только полученный опубликованный каталог. Сообщение **«За эту неделю опубликованных сводок пока нет»** означает отсутствие опубликованного текста за выбранную неделю. Оно не означает отсутствие работ или нулевой результат целей.

## Подготовить свою сводку

1. Войдите под своей учётной записью куратора, откройте нужную неделю.
2. Нажмите **«Подготовить свою сводку»** или **«Изменить свою сводку»** в блоке **«Моя сводка за неделю»**. До нажатия форма свёрнута.
3. Заполните четыре поля. Главная сводка обязательна, до 4000 знаков. В остальных полях пишите один пункт в строке: до 20 пунктов по 1000 знаков; пустые разделы допустимы. Пустые строки между пунктами пропускаются.
4. Нажмите **«Сохранить черновик»**. Появится карточка **«Собственный черновик · не опубликован»**. Директор этого текста пока не видит.

У каждого куратора одна сводка за неделю. Следующее сохранение меняет её редакцию. Свои правки видите вы; чужие неопубликованные черновики недоступны. Опубликованные карточки коллег можно читать, редактирование доступно только для своей сводки.

Пока форма открыта, выбор недели заблокирован, чтобы текст не оказался в другой неделе. **«Отмена»** закрывает форму без сохранения введённых изменений.

## Передать директору

1. После сохранения нажмите **«К публикации»**.
2. В обычном процессе публикации выберите черновик недельной сводки, проверьте состав и отправьте его в готовящийся выпуск `release/current`.
3. Статус **«В готовящемся выпуске · ждёт публикации в main»** означает, что руководитель УОР ещё должен выпустить общую версию в `main`.
4. После выпуска директор обновляет общие данные на своём рабочем месте. Сводка появляется среди карточек **«Опубликовано»**.

Сохранение черновика, отправка в `release/current`, выпуск в `main` и получение общих данных — отдельные действия. Новая локальная правка опубликованной сводки показывается отдельно от прежней общей карточки, пока не пройдёт тот же процесс.

## Если что-то не получилось

| Что видно | Что сделать | Ожидаемый результат |
|---|---|---|
| Нет кнопки подготовки сводки | Проверьте, что выполнен вход куратора | После входа появляется блок своей сводки |
| «Сводка уже изменилась» или каталог изменился во время сохранения | Скопируйте нужный введённый текст, закройте форму, обновите сводки и снова откройте свою запись | Форма откроется с текущей редакцией; сохранение устаревшей версии не затирает чужую правку |
| Ошибка длины или количества пунктов | Сократите соответствующее поле | Допустимый текст сохраняется; при ошибке введённые значения остаются в форме |
| «Не удалось прочитать недельные сводки» | Нажмите **«Обновить сводки»**, проверьте работу локального приложения | Страница повторно читает доступный каталог |
| Директор не видит сохранённый текст | Сверьте неделю, статус черновика, выпуск руководителя в `main` и получение общих данных у директора | После полного цикла появляется опубликованная карточка |

Выпуск через реальный внутренний Git и работа нескольких компьютеров требуют настройки и приёмки банка. Локальные проверки на синтетическом репозитории подтверждают механизм, но не права и доступность корпоративной среды.
