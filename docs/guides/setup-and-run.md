# Запуск и окружение

Действующая пошаговая инструкция — [установка и корпоративный перенос](corporate-transfer.md). Для человека без технической подготовки — [USER_GUIDE](../USER_GUIDE.md).

Новая установка: Node22.20+ветки22.x либо24+, npm,Git и браузер; разрешённая папка; `npm ci`; `npm run setup:workspace -- --mode empty`; локальные аккаунты; `npm run dev`. Подготовка не затирает существующую базу. Демоданные включаются явно. Повторный запуск сохраняет данные.

Настройки места находятся в config/site.local.json, личные файлы — .runtime. ВнутренниеGit/registry/CA/прокси,Сбербраузер/ССО/сертификаты задаются в банке по [runbook](../BANK_CONNECTORS_RUNBOOK.md). Сбор с источников реализован адаптерами; неподдержанная либо отсутствующая настройка возвращает диагноз и не объявляет успешную выгрузку.
