# Создать цель, принять данные и поделиться результатом

25.10.2026. Рабочее место УОР ДИТ Operations.

## Настроить цель

1. Войти как куратор через профиль справа сверху.
2. **Настройка целей → Добавить цель**. Заполнить полное русское название, описание, владельца и куратора. Направление, официальный срок, вес и приоритет — при наличии утверждённых значений.
3. Выбрать методику: число (одно значение/сумма/среднее), доля команд, да/нет (0/1), завершение вех (доля выполненных), диапазон, изменение относительно базы. Указать показатели и пороги. Процентная база изменения не равна нулю.
4. Выбрать ИТ-лидеров. Для доли команд отметить точный состав команд. **Общая цель ДИТ** означает единый результат без персональных назначений; для доли команд всё равно требуется заданный состав.
5. Выбрать существующий источник либо создать ручной, файловый, дашборд или выгрузку со страницы. Дашборд пока имеет заглушку автоматического сбора; его ручная выгрузка принимается с явной отметкой происхождения.
6. Добавить проверочные значения и нажать **Проверить расчёт**. Пример не записывается в факты. Пустой пример допускается, но до реальной загрузки результат неизвестен. После изменения настройки нужна новая проверка.
7. **Сохранить цель в черновики**. Все связанные определения сохраняются вместе. На итоговом экране доступны загрузка реальных данных, карточка и отправка настройки.

В карточке существующей цели **Показатели и источник** открывает этот же мастер. Паспорт, план работ, реальные факты и подтверждение достижения — разные сущности.

## Загрузить реальные данные

**Карточка цели → Загрузить данные**, либо **Источники и факты → Загрузить Excel / CSV**. Выбрать цель, файл или вставку таблицы; сопоставить столбцы и значения с лидерами, участниками и показателями; указать период. Проверить ошибки и расчёт, затем отдельно принять данные. Профиль сохраняется в источнике как черновик.

Поддерживаются UTF-8 CSV и один непустой лист XLSX с заголовками в первой строке, текстовые ISO-даты вида `2026-10-25`. Формулы и неподдерживаемые объекты отклоняются. Файл до 10 МБ, распакованный архив ограничен. Для исходной формы модели зрелости сохраняется специализированный мастер. Это настройка табличного импорта поддерживаемых методик, а не автоматическое понимание любой книги.

У агрегированного результата лидера участником является явно назначенный лидер; у общей цели — общий участник ДИТ. Для доли команд состав задаётся заранее, а не выводится из присутствующих строк. Пустые данные не становятся нулём или успехом. Одинаковые имена требуют явного сопоставления. Идентичный повтор не создаёт редакцию; исправленный факт сохраняет прежний снимок в истории. Исходник остаётся приватным.

## Проверить и отправить

Корректность снимка проверяется кнопкой **Снимок и визуализация верны**. Достижение положительной цели подтверждается отдельно: содержательный комментарий либо файл до 5 МБ. Подтверждение привязано к точному расчёту; при изменении состава/методики/фактов оно не переносится. Ухудшение автоматически становится невыполнением.

**Отправить в репозиторий** отправляет связанные черновики в `release/current`. Руководитель выпускает в `main`, коллеги получают общие данные кнопкой обновления. Независимые правки объединяются; конфликт одного поля сохраняет черновик. Графический разрешитель такого конфликта пока отсутствует.

Публичный тестовый RM_UOR принимает только демонстрационные данные. Рабочая карта публикуется после настройки разрешённого корпоративного Git. До распространения новых методик/профилей сначала обновить код и зависимости клиентов, затем перезапустить приложение.

## Дополнительные страницы

- **Повестка директора** — ближайшие даты/просрочки/прогнозы, реальные изменения за семь дней, решения с ответственным/сроком/основанием закрытия.
- **Отчёты и презентации** — состав и период, неизменяемый снимок, HTML для печати/PDF, PPTX, сохранение профиля. Шаблон пока встроенный. Исторические факты пересчитываются по текущим правилам с предупреждением; это не восстановление прежней оргструктуры.
- **База знаний** — объекты, лидеры продуктов, статьи/методики простым текстом, связи, поиск, мягкий архив и восстановление. Используемый объект архивировать нельзя.

Реальные корпоративный сбор, сертификаты/SSO, macOS/СберОС, свободный PPTX-конструктор и автоматический прогноз остаются отдельными этапами приёмки.
