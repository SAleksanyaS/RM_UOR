# Команды и объекты цели

Войдите как куратор, откройте карточку цели → «Настроить цель» → нужного ИТ-лидера в назначениях.

«Команды в расчёте» — ожидаемые участники расчёта по командам. Включите нужные галочки; для длинного списка есть поиск и выбор видимых записей. Если состав раньше не задавался, он остаётся неизвестным до вашего явного выбора. Снятые галочки не удаляют команды из базы знаний и не стирают прошлые факты.

«Продукты и объекты карты» — область ответственности из исходной карты и справочника. Её названия не превращаются автоматически в расчётные команды. Готовый сводный числовой факт источника не пересчитывается из текстовых названий продуктов; для такого изменения нужна соответствующая методика или новая выгрузка.

Чтобы добавить пункт, введите название, выберите тип и нажмите «Добавить в список». Он появится с галочкой. Если галочку снять, запись всё равно сохранится в базе знаний, но не включится в это назначение. Можно последовательно добавить несколько пунктов. Сервер повторно использует однозначную существующую запись вместо создания дубля.

«Сохранить черновик» сохраняет назначение и новые справочные записи на этом компьютере одним действием. «Сохранить и отправить» затем запускает существующую общую публикацию. Если отправка недоступна, черновики сохраняются. После выпуска и обновления репозитория коллеги получают новый состав.

Если назначение уже изменилось, форма попросит обновить карточку; введённые значения останутся доступны. При ошибке записи назначение и справочник не принимаются частично. Если часть нескольких назначений уже сохранена, повтор не создаёт заново принятые элементы.

Изменение состава снимает прежнее подтверждение выполнения. Добавленная команда без фактов становится отсутствующим ожидаемым участником; это нельзя считать полным выполнением. Пустой или неизвестный состав также не означает 100%.
