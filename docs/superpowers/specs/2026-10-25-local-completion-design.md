# Завершение локального рабочего места и интерфейс

25.10.2026. Пользователь поручил закончить все перечисленные локальные задачи, начать с полного профиля предоставленного maturityPPTX, остальные вести параллельно; запустить и push без остановок. Отдельно: сворачиваемая навигация/иконки и независимая оценка цветов/расположения.

## Решения

1. Приоритет — полный встроенный профиль maturity для исходного11-слайдового PPTX, а не пробная замена. Каждое динамическое значение имеет источник в зафиксированном отчёте; старые числовые примеры не остаются как будто актуальные. Нет данных — явно неизвестно, прошлые периоды не выдумываются. Исходные masters/layout/theme/редактируемые блоки сохраняются, rawкорпоративный шаблон/результат приватны. Поддержанный профиль доступен черезUI, генерация повторяема.
2. Переносимый bundle: логические данные+проверенные артефакты с hash/manifest/rollback, без паролей, сессий, профиля браузера и приватных ключей. Управляемое сохранение исходников/отчётов, восстановление привязок владения для новогоПК и текущего куратора по явному выбору. Очистка — сначала preview и обратимый карантин, ссылки из оставшихся данных защищены; сроки задаются политикой. История вех получает сегменты вместо отказа по конечному лимиту.
3. Обновление программы сначала готовит доверенный код/зависимости в разрешённой папке, пока старая версия работает. Затем IPCquiesce/CAS/ff-only/swap. Ошибка нового запуска возвращает предыдущий работоспособный код/зависимости с журналом; пользовательские файлы не сбрасываются.
4. Навигация: компактная полоса иконок по умолчанию, явная кнопка раскрытия подписей, личное сохранение режима, доступные имена/фокус; на телефоне отдельная панель. Меню соблюдает роли. Развёрнутое меню не обрезает контент и не лишает места таблицы.
5. UI: нейтральный фон/белые поверхности, один изумрудный акцент действий, различимые красный/янтарный/зелёный/серый статусы с подписями. Текст темнее/контрастнее, единая сетка/интервалы, детали по запросу. Обзор показывает итог и лидеров; полный каталог не перегружает первый экран. Используются существующие Salute tokens; замена всей библиотеки не требуется.

Корпоративные адреса/SSO/ОС/Office-политики не угадываются; локальный прогон не объявляется банковской приёмкой. Полный профиль принимается на исходном файле локально с визуальным осмотром всехслайдов; Officeвбанке отдельный.

Варианты навигации: полностью спрятанная требует лишнего поиска; постоянная широкая отнимает место. Выбран управляемый rail+подписи. Варианты обновления: установка после остановки оставляет неработающийПК при сетевом отказе; stagedprepare+recover сохраняет работающую версию.
