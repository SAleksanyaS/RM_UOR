# Обзор портфеля и выбор команд — план реализации

> **For agentic workers:** Use superpowers:subagent-driven-development for independent model, overview UI and scope UI tasks; root integrates backend and verification.

**Goal:** Общая картина всех целей ДИТ с выбором отдельной цели и самостоятельным изменением команд/объектов через галочки.

**Architecture:** Чистая портфельная модель поверх существующих оценок; отдельный UI обзора. Атомарная серверная команда сохраняет справочные записи и назначение в SQLite-черновики, передаваемые существующей публикацией.

**Tech Stack:** React/TypeScript, SDDS, Fastify, SQLite; без новых зависимостей.

**Spec:** `docs/superpowers/specs/2026-10-24-portfolio-and-team-scope-design.md`.

## Ограничения и фокус проверки

- Не усреднять факты разных целей; различать цели и назначения. Нет данных — неизвестность.
- Общая цель может допускать часть отклоняющихся лидеров; её официальный глобальный расчёт сохраняется.
- Галочки реальных команд меняют participantIds, названия продуктов/групп не подменяют расчётный состав.
- Неизвестный состав не сужается автоматически до известных команд. Снятие галочки не удаляет справочник/историю.
- Читатель не записывает; устаревшая форма/ошибка сохраняет прежнее назначение; справочник и назначение принимаются вместе.
- Русские полные названия, текст/иконки в дополнение к цветам, ноутбук/большой/узкий экран.
