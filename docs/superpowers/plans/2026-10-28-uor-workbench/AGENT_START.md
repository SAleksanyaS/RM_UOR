## Чего нельзя выдавать за выполнение

- План, тестовый пример и assertion в Markdown не являются запущенным тестом.
- Проход синтетического Git/Qlik/Chromium fixture не доказывает корпоративный вход.
- `npm run build` проверяет TypeScript/Vite, но не успешный запуск backend или Node22 совместимость сам по себе.
- Локальная ветка без успешного push не является опубликованной GitHub-веткой.
- Успешный push не означает созданный PR, Git-вход не означает REST-вход.
- Чтение main не создаёт новое подтверждение цели, пятничная проекция не создаёт измерение.

Текущая поставка этого запроса — согласованные документы и проверенный план. Реализация T00–T48 начинается отдельным выполнением этого стартового запроса.
