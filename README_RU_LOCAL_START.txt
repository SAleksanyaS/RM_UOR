РМ УОР 0.6 — ЕЖЕДНЕВНЫЙ ЗАПУСК

1. Используйте подготовленный ИТ комплект Linux x64 и установленный СберБраузер152.0.7977.120.
2. Откройте ярлык «РМ УОР» или START_RM_UOR.sh. Зависимости каждый день не устанавливаются.
3. Оставьте окно запуска открытым. Интерфейс откроется в выбранном СберБраузере. Если путь не настроен, окно покажет локальный адрес; подготовку автоматического запуска завершает ИТ.
4. В «Настройки → Рабочее место» проверьте версии и доступность папки.
5. В «Данные» выберите файл, ручной ввод, ОКО или Confluence. Для сохранения исходника каталог и цель не нужны.
6. После работы остановите приложение Ctrl+C в окне запуска. Не удаляйте рабочую папку.

Тема — значок палитры вверху. Сворачивание меню — внизу слева. Быстрый переход — кнопка поиска вверху.
Общие данные/код/пакеты настройки — «Обновления и копии». Личная копия — «Обслуживание».
Для поддержки: «Настройки → Скачать диагностику». Файл не содержит исходных выгрузок и сеансов.

ПОДГОТОВКА ИТ
Закреплённые Node22.16.0/npm10.9.2 и lock-файл обязательны. В готовом Linux-комплекте они уже вложены; кодовый ZIP требует установки зависимостей. Создание ярлыка и проверка точного пути СберБраузера описаны в docs/guides/setup-and-run.md.
Windows START_RM_UOR.cmd сохранён для совместимости; Windows-поставка0.6 отдельно в этой среде не принята.

Личная резервная копия, пакет общих настроек и обновление кода — разные операции. Профили браузера, cookies, сертификаты, роли и токены коллегам не передаются.
Полное руководство: docs/guides/product-0.6.md и PDF из комплекта выпуска.
