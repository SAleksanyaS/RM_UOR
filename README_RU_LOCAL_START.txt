РМ УОР — запуск на вашем компьютере Windows
=========================================

Нужны установленный Node.js 22.16.0 с npm 10.9.2 и браузер. При первой
установке зависимостей нужен доступ к настроенному npm registry.
Launcher не скачивает и не устанавливает Node.js и не меняет политику PowerShell.

ДВА ШАГА
1. Распакуйте весь архив в НОВУЮ короткую папку, например C:\RM_UOR_Local.
   Не распаковывайте поверх RM_UOR-0.5-preview или другой рабочей установки.
2. Дважды щёлкните START_RM_UOR.cmd. Первый запуск установит зависимости,
   запустит приложение и откроет браузер. Оставьте окно запуска открытым.
   Если браузер не открылся, после сообщения о готовности перейдите на
   http://127.0.0.1:5173/overview. Остановка — Ctrl+C в окне запуска.

Первое открытие
--------------
Новое рабочее место пустое: показано «Пока нет общего каталога».
«Данные → Личные выгрузки ОКО» доступны сразу. Демонстрационные цели,
автоматическая запись ОКО и обращение к банковским системам не запускаются.
Для реальной выгрузки вы сами задаёте адрес отчёта и установленный браузер,
выполняете ручной вход/сертификатные действия. Для общего каталога нужна
своя совместимая копия или отдельно принятая настройка интеграции.
Временные роли «Читатель / Редактор» не дают банковских прав; local-preview
не разрешает внешнюю отправку пакета или применение main.

Что делает launcher
-------------------
Проверяет именно Node.js 22.16.0 и npm 10.9.2, использует npm того же Node.
Создаёт config/site.local.json только если файла ещё нет. Разрешённой папкой
будет эта распакованная копия; по умолчанию API — 4174, интерфейс — 5173,
autoOpen — true, roleMode — local-preview, repositoryUrl — пустая строка.
Устанавливает npm ci --include=dev --no-audit --no-fund только если
node_modules отсутствует; dev-зависимости нужны штатному npm run dev.
Запускает штатный npm run dev. Сборка и тесты автоматически не выполняются.
Существующие настройки и .runtime не удаляются и не заменяются.
Повторный запуск из той же папки использует сохранённое состояние.

Если запуск остановился
----------------------
• Node/npm не найдены или отличаются от указанных версий: установите
  согласованные версии обычным способом и запустите START_RM_UOR.cmd снова.
  Автоматический системный установщик не запускается.
• Порт занят: если эта копия уже открыта, пользуйтесь её окном браузера.
  Иначе выберите два свободных разных порта в config/site.local.json,
  например port=4176 и clientPort=5175, затем повторите запуск. Новый адрес
  будет http://127.0.0.1:5175. Чужие процессы launcher не останавливает.
• npm ci прервался или node_modules неполный: исправьте доступ к registry,
  затем откройте терминал в этой новой папке и выполните
  npm ci --include=dev вручную.
  Launcher не переустанавливает существующие зависимости автоматически.
• После переноса папки: проверьте allowedWorkspaceRoots в существующем
  config/site.local.json. Он должен содержать новый существующий абсолютный
  путь (в JSON удобно использовать C:/RM_UOR_Local). Launcher не исправляет
  существующий файл без вашего решения.
• Окно запуска сообщает ошибку: не удаляйте .runtime ради повторного старта.
  Она содержит рабочие данные. Сохраните сообщение для диагностики.

Это отдельная новая установка. Пользовательский Windows preview, его база,
конфигурация и новые локальные коммиты этим архивом не обновляются.
Резервные копии рабочих данных делаются отдельно штатным обслуживанием.
Сайт слушает только localhost вашего компьютера; публичного хостинга нет.
