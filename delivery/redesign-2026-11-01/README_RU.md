Для каждого из 24 коммитов проверены точное совпадение дерева с исходным коммитом, порядок родителей и исходные метаданные в сообщении; созданные коммиты повторно прочитаны из GitHub.

## Файлы

- [commit-map.json](commit-map.json) — исходные и GitHub SHA, соответствующие деревья, родители, исходные и опубликованные метаданные, результаты чтения GitHub.
- [RM_UOR_SourceHistory.bundle](RM_UOR_SourceHistory.bundle) — 24 оригинальных коммита с первоначальными SHA, авторами, датами, сообщениями и родителями. Bundle инкрементальный: единственная prerequisite — общая база из таблицы.
- [bundle-verification.json](bundle-verification.json) — результат независимого восстановления оригинальной истории из отдельной base-only копии.

## Восстановление оригинальных Git-объектов

Выберите новые, ещё не существующие имена каталогов. Нужен Git и доступ на чтение репозитория.

```text
git clone --single-branch --branch codex/uor-redesign-reference https://github.com/SAleksanyaS/RM_UOR.git RM_UOR_published
cd RM_UOR_published
git bundle verify delivery/redesign-2026-11-01/RM_UOR_SourceHistory.bundle
git fetch ./delivery/redesign-2026-11-01/RM_UOR_SourceHistory.bundle refs/heads/source-history-7453624:refs/heads/archive/original-7453624
git worktree add ../RM_UOR_original_7453624 archive/original-7453624
git -C ../RM_UOR_original_7453624 rev-parse HEAD
git -C ../RM_UOR_original_7453624 rev-parse "HEAD^{tree}"
```

Последние две команды должны вернуть исходный HEAD и дерево из таблицы. Если выбранные каталог или локальная ветка уже существуют, используйте другие имена. Исходные author/date восстанавливает bundle; текстовая карта сама по себе их не заменяет.

## Область проверки

Bundle проверен в независимой копии, первоначально содержавшей только точную базу. До fetch исходного HEAD там не было; object alternates не использовались. `git bundle verify` завершился с кодом 0. После fetch совпали HEAD, дерево, последовательность всех 24 коммитов и байты всех исходных commit objects; detached checkout чистый.

Эти проверки подтверждают сохранность истории и точность переноса. Они не являются новым прогоном тестов приложения. Результаты единственного полного suite, последующих адресных исправлений и границы банковской приёмки перечислены в [итоговом журнале](../../docs/validation/redesign-completion.md). Личные профили, рабочие данные, сертификаты, ключи и локальные настройки в эту папку не включены.
